# Contributing to Vonix Network

We welcome contributions from the community! Please follow these guidelines to ensure a smooth and effective process.

## Code of Conduct

This project and everyone participating in it is governed by our [Code of Conduct](./CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## How to Contribute

1.  **Fork the repository** and create your branch from `main`.
2.  **Make your changes** in your forked repository.
3.  **Ensure your code lints** and follows the project's coding style.
4.  **Write tests** for any new functionality.
5.  **Submit a pull request** with a clear description of your changes.

## Pull Request Process

1.  Fill out the required pull request template.
2.  Ensure all status checks are passing.
3.  A project maintainer will review your pull request and provide feedback.
